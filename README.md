# ⛅ Weather Hub

A modern and responsive weather application built with React that provides real-time weather information, air quality insights, and a 5-day weather forecast for cities around the world.

## 🌐 Live Demo

🔗 Live Website: https://karib19.github.io/weather_app-project/

## 📂 Repository

🔗 GitHub Repository: https://github.com/karib19/weather_app-project

---

## ✨ Features

* 🔍 Search weather by city name
* 💡 Smart city autocomplete suggestions
* 🌡️ Real-time temperature updates
* 🤗 Feels-like temperature display
* 💧 Humidity information
* 💨 Wind speed details
* 📊 Atmospheric pressure data
* ☀️ UV Index monitoring
* 👀 Visibility information
* 🌫️ Air Quality metrics (PM2.5, PM10, O₃)
* 📅 5-Day weather forecast
* 🕒 Recent search history
* ⚠️ Error handling for invalid city names
* 📱 Fully responsive design

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/karib19/weather_app-project.git
```

### Navigate to the Project Directory

```bash
cd weather_app-project
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
